# ⌨️ Typing Speed Test

**Made fast, for the fast — Shankar 🚀**

A modern and responsive Typing Speed Test web app built using **HTML**, **CSS**, and **JavaScript**.  
It helps users measure their typing speed (WPM), accuracy, and track mistakes — all in a clean and elegant interface.

---

## 🌟 Features

✅ **Dynamic Paragraphs** – Random simple test paragraphs for real typing practice.  
✅ **Custom Time Options** – Choose between 30s, 60s, or 120s test durations.  
✅ **Real-Time Stats** – Track WPM, accuracy, mistakes, and character count instantly.  
✅ **Progress Bar** – Visual timer progress indicator.  
✅ **Dark/Light Mode** – Switch between your preferred themes effortlessly.  
✅ **Responsive Design** – Works smoothly on desktop and mobile.  
✅ **Restart Button** – Instantly restart with a single click.

---

## 🧠 Tech Stack

- **HTML5**
- **CSS3 (Flexbox, Animations, Dark Mode)**
- **JavaScript (DOM Manipulation, Event Handling)**
